# Omar Allahham Portfolio

Static HTML/CSS/JavaScript portfolio for Omar Allahham.

## Pages

- `index.html` - home, intro, featured projects
- `about.html` - profile, background, credentials
- `skills.html` - technical skills and tools
- `experience.html` - internship, open source, education
- `projects.html` - project showcase and filters
- `contact.html` - contact details and Formspree form

## Run Locally

Open `index.html` directly in a browser, or serve the folder with any static server.

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
